# Mở danh bạ phụ huynh

Trang dùng chung để giáo viên chủ nhiệm mở file danh bạ lớp (`lop-xxx.html`) trên iPhone/Android.
Trang **không chứa dữ liệu học sinh**: GVCN chọn file danh bạ do nhà trường gửi, nhập mật khẩu,
dữ liệu được giải mã ngay trên máy (AES-256), không gửi lên mạng.

Không đưa file `lop-xxx.html`, file Excel hay mật khẩu vào kho này.
